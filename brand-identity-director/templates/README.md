# Output templates

Copy and fill only the forms needed. Bracketed fields are intentional prompts. Remove unused sections in client-facing output; never fill unknowns with invented facts.

- [Intake brief](intake-brief.md): discover / provisional exploration.
- [Strategy](strategy.md): positioning, criteria, decision/evidence ledger.
- [Concepts](concepts.md): explore / selection rationale.
- [Critique scorecard](critique-scorecard.md): critique / refine / release.
- [Brand guidelines](brand-guidelines.md): design / deliver.
- [Handoff](handoff.md): deliver / release status and asset manifest.
- [Application specification](application-spec.md): packaging, marketing, digital.
