# Visual systems and art direction

R1 §5.2 supports context-first thinking (`REPORT-H`). This system framework is `PRACTICE` and extends beyond logo construction.

## Define the grammar

Turn the concept into repeatable relationships: hierarchy, spacing rhythm, type roles, color roles, image treatments, framing/cropping, icon or illustration logic, and information density. Specify invariants (for example consistent product naming hierarchy) and variables (for example seasonal photography). Avoid deriving every decorative element from the logo; a system must support content independently.

Build a color role table: brand accent, surfaces, text, links/actions, borders, statuses, and inverse equivalents. Record sRGB values and approved foreground/background pairs, not just swatches. Establish dark/light behavior explicitly. For print, describe intended appearance and obtain medium-specific conversions and proofs; SVG hex values are not CMYK specifications.

Create a type/layout specimen with short and long headlines, body copy, captions, prices/data, multilingual strings, and a dense edge case. Define columns, margins, alignment, responsive behavior, and vertical rhythm as useful rules rather than arbitrary fixed grids. Test ambiguity and hierarchy at final viewing size.

## Direct imagery and motion

For photography: subjects, casting/representation, environment, light, perspective, crop, texture, retouch limits, content authenticity, and rights. Show concrete do/don't pairs. For illustration/icons: stroke or fill logic, corner treatment, perspective, detail level, and meaning. Record licensing and generative provenance; no fabricated product features, environmental claims, or endorsements in marketing images.

If motion is in scope, state purpose (recognition, orientation, feedback), characteristic timing/behavior, reduced-motion alternative, and contexts where motion is unnecessary. Do not make essential information depend on animation or flashing. An animated logo is a separate export/QA path; the bundled static SVG profile rejects animation.

## Prove the grammar across media

Stress-test one small repetitive use, one dense informational use, and one expressive use. For example: avatar, product label, and campaign page. Include realistic copy and production constraints early. A marketing system can be expressive while a transactional UI remains clear; define the relationship instead of forcing identical density everywhere.

Document examples and counterexamples in [guidelines](../templates/brand-guidelines.md), plus token names/version, responsive variants, and ownership. A system is ready when another designer can make a plausible new application using its rules without inventing the identity again.
