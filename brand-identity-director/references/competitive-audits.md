# Competitive and category audit

R1 §5.1 and R2 §5 suggest a 20-logo board (`REPORT-H`). Twenty is a starting exercise, not a statistically representative sample or legal search. “Ownability gap” means a design opportunity here, never unclaimed trademark rights.

## Build an auditable sample

Define category, geography, price tier, audience, channel, date, and inclusion rules. Separate direct competitors, substitute solutions, and aspirational references. Use official current sources where available, record URL/access date and asset version, and mark missing evidence. If browsing is unavailable, audit supplied examples and state the incomplete scope; do not fabricate a competitor board.

Capture names and wordmarks as well as symbols. Normalize apparent visual scale without distorting aspect ratios. Keep original artwork alongside any analytical mask; masking names is optional and unsuitable when typography is the identity's distinguishing element. Store assets only with appropriate permissions and cite owners. Do not publish a competitor asset collection as original work.

Record logo architecture, geometry, typography traits, color roles, imagery, messaging, application behavior, and distinctive assets. Look beyond hue: repeating an uncommon composition or negative-space device can create stronger similarity than sharing a common color. Use thumbnails and monochrome comparisons to inspect dominant silhouettes.

## Synthesize an opportunity

Separate observed pattern → audience/category need → opportunity hypothesis → risk. An empty visual territory may be unused because it performs poorly. Test whether a proposed departure preserves enough category comprehension. A brief can deliberately retain conventions for usability while differentiating in arrangement, language, imagery, or system behavior.

For each finalist, compare the closest visual/name neighbors side by side. Record differences and unresolved similarity concerns without asserting originality. No pixel-distance metric or competitor count proves non-infringement. Read [rights](rights-and-trademark.md) for jurisdiction-sensitive specialist review.

Deliver an audit table, sourced board, limitations, 2–4 useful opportunity statements if supported, and design criteria. The count is flexible. Do not use famous identity elements as templates for a new mark; translate the strategic lesson rather than copy distinctive expression.
